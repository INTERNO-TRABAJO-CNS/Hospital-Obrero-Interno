# Diagramas de comportamiento — CNS

Esta carpeta contiene los **diagramas UML de los casos de uso** del Sistema de Gestión y Control de Citas Médicas del Hospital Obrero (CNS). Su objetivo es que el equipo comprenda cómo interactúan los actores con el sistema antes de implementarlo.

## Contenido

- **CU-00:** diagrama general que reúne los casos de uso del sistema.
- **CU-01 a CU-20:** diagramas individuales, de acuerdo con la especificación de casos de uso.
- **Archivos `.puml`:** código fuente editable en PlantUML.
- **Imágenes `.png`:** diagramas exportados para revisión y presentación.

## Indicaciones para el equipo

1. Usar como referencia el documento **Especificación de Casos de Uso CNS**.
2. Mantener los nombres y códigos de cada caso de uso en el diagrama correspondiente.
3. Modificar primero el archivo `.puml` y actualizar su imagen `.png`.
4. Subir los cambios a la rama asignada y solicitar revisión mediante un *Pull Request*.

> **Importante:** si se modifica un caso de uso, revisar también su diagrama para mantener la documentación consistente.
