Exportación individual de diagramas UML — 03_Casos_de_Uso

Cada subcarpeta contiene UN diagrama en los siguientes archivos separados:
- .puml: código original, sin cambios.
- .svg: imagen vectorial.
- .png: imagen rasterizada de alta resolución.

Importante: En este entorno se utilizó un motor local Graphviz que reconstruye
visualmente el contenido y las conexiones de los archivos PlantUML; por tanto,
la distribución visual y algunas convenciones gráficas pueden diferir de
una exportación nativa con PlantUML. No se modificó el código fuente .puml.
