03\_Design (Análisis y Diseño)

Aquí se define cómo se construirá el sistema, desarrollando los requistos a una solución de software.

¿Qué archivos deben subirse aquí?



Documento de arquitectura del sistema.

* Diagramas UML relacionados con los casos de uso y comportamiento del sistema.
* Diagramas de secuencia.
* Diagramas de actividades.
* Diagramas de clases.
* Diseño de la arquitectura cliente-servidor.
* Diseño de la aplicación móvil desarrollada en Flutter.
* Diseño del Backend desarrollado en Java con Spring Boot.
* Diseño y documentación de los endpoints de la REST API.
* Diseño de la comunicación en tiempo real mediante WebSocket.
* Diseño del modelo de datos y base de datos cuando la tecnología sea definida.
* Prototipos y diseños de interfaces del sistema.
* Diagramas de componentes y despliegue cuando corresponda.



\## Arquitectura tecnológica definida



Actualmente el proyecto contempla las siguientes tecnologías:



\- \*\*Frontend:\*\* Flutter.

\- \*\*Backend:\*\* Java con Spring Boot.

\- \*\*Comunicación cliente-servidor:\*\* REST API.

\- \*\*Comunicación en tiempo real:\*\* WebSocket.



La tecnología de base de datos, infraestructura de despliegue y otros servicios complementarios serán definidos posteriormente durante el desarrollo del proyecto.
