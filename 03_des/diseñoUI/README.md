# Diseño de interfaz de usuario (UI) — CNS

Esta carpeta reúne los **bocetos, prototipos y diseños de pantallas** del Sistema de Gestión y Control de Citas Médicas del Hospital Obrero (CNS). Sirve como guía visual para desarrollar la aplicación móvil en **Flutter**.

## Contenido

- **Pantallas:** diseños de inicio de sesión, solicitud y consulta de citas, entre otras funciones definidas para el sistema.
- **Flujos de navegación:** recorrido del usuario entre pantallas.
- **Recursos visuales:** imágenes, íconos y elementos reutilizables del diseño.
- **Prototipos:** archivos o enlaces al diseño interactivo, cuando estén disponibles.

## Indicaciones para el equipo

1. Diseñar según los requisitos, casos de uso y roles del sistema: **paciente, enfermería/admisión, médico y administrador**.
2. Mantener coherencia en colores, tipografías, botones y mensajes.
3. Considerar pantallas claras, accesibles y adaptables a dispositivos Android.
4. Guardar los cambios con nombres descriptivos y enviarlos a revisión antes de implementarlos en Flutter.

> **Importante:** una pantalla no debe introducir funcionalidades que no estén respaldadas por los requisitos del proyecto.
