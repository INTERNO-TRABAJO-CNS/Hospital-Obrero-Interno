\# 01\_Business Modeling - Modelado del Negocio

En esta carpeta documentamos la justificación del proyecto, el contexto del problema y quiénes son los interesados directos en el sistema.



Esta carpeta es puramente para entender el negocio y el problema que resolvamos



\#¿Qué archivos deben subirse aquí?

* Documentación relacionada con la situación actual del proceso de citas médicas.
* Definición y descripción del problema.
* Modelo del negocio.
* Procesos actuales de atención y asignación de citas.
* Reglas del negocio.
* Identificación de actores involucrados.
* Información obtenida mediante entrevistas al personal.
* Diagramas del flujo actual del negocio.
* Documentos relacionados con las necesidades del Hospital Obrero.



\## Objetivo



Comprender el funcionamiento actual del proceso de gestión de citas médicas para identificar problemas, necesidades y oportunidades de mejora que serán consideradas en el desarrollo del sistema.
