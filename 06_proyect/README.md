\# 06\_proyect - Gestión y Entorno (Project Management \& Environment)



En esta carpeta se almacena la documentación relacionada con la planificación, organización, seguimiento y gestión general del proyecto del Sistema de Gestión y Control de Citas Médicas del Hospital Obrero de la Caja Nacional de Salud (CNS).



También se documentará la configuración del entorno de trabajo utilizado por el equipo durante el desarrollo del sistema.



\## ¿Qué archivos deben subirse aquí?



* Cronogramas y planificación general del proyecto.
* Diagramas de Gantt.
* Distribución y asignación de tareas entre los integrantes del equipo.
* Planificación de iteraciones y avances del proyecto.
* Actas de reuniones y acuerdos del equipo.
* Informes de seguimiento y avance.
* Documentación relacionada con la metodología de desarrollo utilizada.
* Configuración general del entorno de desarrollo.
* Instrucciones para preparar y ejecutar el proyecto en un entorno local.
* Documentación de configuración de Flutter.
* Documentación de configuración de Java y Spring Boot.
* Configuración necesaria para REST API y WebSocket.
* Documentación de control de versiones y trabajo colaborativo mediante Git y GitHub.
* Documentación de despliegue e infraestructura cuando estas tecnologías sean definidas.



\## Tecnologías actualmente consideradas



El proyecto contempla actualmente:



\- Flutter para la aplicación móvil.

\- Java con Spring Boot para el backend.

\- REST API para la comunicación cliente-servidor.

\- WebSocket para las actualizaciones en tiempo real.

\- Git y GitHub para el control de versiones y trabajo colaborativo.



La infraestructura definitiva, tecnología de base de datos, servidor de despliegue y otros servicios serán definidos posteriormente.
