# Herramientas recomendadas para VS Code — CNS

| Herramienta | Para qué sirve |
|---|---|
| Extension Pack for Java | Java y Spring Boot. |
| Spring Boot Extension Pack | Navegar y ejecutar el backend Spring Boot. |
| Flutter y Dart | Desarrollo y depuración de la app móvil. |
| PlantUML | Diagramas `.puml` de arquitectura, clases y secuencias. |
| Markdown Preview Enhanced (opcional) | Visualizar `.md`. |
| GitLens (opcional) | Historial y autoría de commits. |

Se requieren JDK, Flutter SDK y acceso a PostgreSQL de desarrollo según la configuración que apruebe el equipo. No instalar C++ por copiar la configuración de ChuroViaje.
